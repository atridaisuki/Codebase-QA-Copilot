# 后端 + AI 应用实习面试知识清单

## 1. 使用方式

这份清单不是让你一次全背完，而是按下面顺序准备：

1. **先会讲项目**
2. **再补后端基础**
3. **再补数据库 / 缓存 / 部署**
4. **最后补 RAG / Agent 专项**

建议把每个知识点分成 3 个层次：

- **知道概念**：能说出定义
- **知道为什么**：能说出使用场景和 trade-off
- **能结合项目回答**：能结合你这个项目举例

## 14. 面试准备建议

## 14.1 每个知识点用这个模板准备

### 模板
1. 是什么
2. 为什么需要
3. 怎么实现 / 怎么用
4. 优缺点 / trade-off
5. 在你项目里怎么体现

例如：

### “为什么要做 chunk？”
- 是什么：把长文档切成适合 embedding 和检索的小片段
- 为什么：长文档整体向量化会导致检索定位不准
- 怎么做：按段落切、超长再降级切块
- trade-off：太大召回不准，太小上下文碎片化
- 项目体现：我们从固定字符窗升级到段落优先切分

---

## 14.2 项目面试时尽量这样表达

不要只说：
- “我用了 Chroma”
- “我用了 Claude”

要说成：
- “为了提升检索质量，我在 retrieval v2 中增加了 score 过滤、相邻 chunk 合并和 context budget 控制”
- “为了降低无依据回答，我把 grounded 判定从 token overlap 改成基于检索质量的判断”
- “为了保证可迭代性，我为 splitter、retrieval、qa 增加了测试覆盖”

这种说法更像工程项目，而不是 API 拼装。
